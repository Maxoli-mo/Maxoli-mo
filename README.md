# Mo

I build free and open-source software around AI assistants, Android, and Kotlin Multiplatform.

## What I'm working on

**[Maxit](https://github.com/Maxoli-mo/Maxit)** — an in-development, GPL-3.0-only fork of [Kai](https://github.com/SimonSchubert/Kai). I'm maintaining the Android FOSS, Linux desktop, and Web targets. It brings together configurable model providers, persistent memory, tools, and MCP connections. **There is no Maxit release yet**; the repository includes source code and build instructions.

## Useful things from the work so far

- [Build Maxit from source](https://github.com/Maxoli-mo/Maxit#build-from-source) — commands for Android, Linux desktop, and Web.
- [Lower-resource Gradle development notes](https://github.com/Maxoli-mo/Maxit#lower-resource-development) — practical build settings and troubleshooting notes for constrained machines.
- [Getting started](https://github.com/Maxoli-mo/Maxit/blob/main/docs/getting-started.md) — provider setup and first steps.

I care about software people can inspect, adapt, and run themselves. Follow the repository if you want to see the project develop; contributions and specific bug reports are welcome.
